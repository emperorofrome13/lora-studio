Test LoRAs with ComfyUI

      
LoRA Tester runs every LoRA you import through a strength matrix (8 strengths × 5 prompts) on a ComfyUI checkpoint or diffusion model, burns the LoRA name and strength into each image, and builds a contact sheet. Finished runs can be sent straight to the Grid tab's LoRA strength grid.

      
    
        
  • Needs Python 3.10+ (the first start creates a private environment and installs Flask and Pillow, about a minute).
    • 
        
  • Needs ComfyUI running on this computer (usually http://127.0.0.1:8188).
    • 
        
  • Runs locally only. Nothing is uploaded.
